# Step-by-Step Diagram Explainer

**Use it for:** how something works, processes and cycles (water cycle, photosynthesis, how
a vaccine works, how a bill becomes law), workflows and tutorials.

**Do not use it for:** stories with no sequence, or more than 7 steps (split into parts).

## How it looks
Numbered circular nodes on a faint grid (zig-zag on portrait, row on landscape); each node
pops in and the arrow to it draws itself when its narration starts; the active step glows
in the accent color; `cycle` draws a return arrow from the last step to the first.
Palettes: `blueprint`, `chalkboard`, `clean`.

## Filling the props (fill tier)
- Write **one narration scene per step** so highlighting follows the voice exactly.
- `label` ≤ 3 words; `detail` one line; `symbol` is a short text glyph (no emoji).
- Accuracy matters: explain the real mechanism, simply.

## Product placement
`<AdWeave>` for topic explainers; `native-integrated` turns it into a product workflow
("Upload → Plan → Publish").

## Forking ideas
Replace nodes with hand-drawn SVG icons, add a progress bar, or animate particles flowing
along the arrows.
