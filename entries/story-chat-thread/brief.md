# Chat Thread Story

**Use it for:** stories told as a text conversation — relatable situations, dramatized
historical moments ("if Fleming had a group chat"), customer stories, plot twists.

**Do not use it for:** fake screenshots presented as real conversations between real
people. Dramatizations must set `label` (e.g. "Dramatized — not a real conversation").

## How it looks
A phone messaging UI (dark or light): header with contact + status, bubbles that pop in
with spring scale, a typing indicator before each incoming message, timestamps, auto-scroll.
Timing is allocated by message length across the whole video. 9:16 only.

## Filling the props (fill tier)
- `messages`: 2–16, short and punchy; save the twist for the last message.
- `status` doubles as setting ("Rome, 44 BC").
- Narration is optional — the chat carries the story; light narration can set the scene.

## Product placement
`<AdWeave>`: end-card or sponsor-mention. For `native-integrated`, the product can solve the
problem in the conversation — keep it believable and labelled as a dramatization.

## Forking ideas
Add photo/voice-note bubbles from scene images, reactions on bubbles, or a split screen of
two phones.
